# 🧠 Brain Tumor MRI Classification Using Deep Learning

## 📌 Project Description
This project uses **Deep Learning** to classify brain MRI images into four different categories. It uses CNN and EfficientNetB0 Transfer Learning to identify image classes.

## 🏷️ Classes
1. 🧬 Glioma
2. 🧠 Meningioma
3. 🔬 Pituitary
4. ✅ No Tumor

## 🛠️ Technologies Used
- 🐍 Python
- 🤖 TensorFlow
- ⚙️ Keras
- 🧠 CNN (Convolutional Neural Network)
- 🚀 EfficientNetB0
- 🌐 Streamlit
- 🖼️ OpenCV
- 🔢 NumPy
- 🐼 Pandas
- 📊 Scikit-learn

## ✨ Features
- 🖼️ MRI Image Classification
- 🔄 Image Preprocessing
- 🧩 Data Augmentation
- 🧠 Custom CNN Model
- 🚀 EfficientNetB0 Transfer Learning
- 📈 Model Evaluation
- 🔍 Grad-CAM Visualization
- 🌐 Streamlit Web Application

## 📂 Dataset
The project uses the Brain Tumor MRI Dataset from Kaggle.

🔗 **Dataset Link:**  
https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

## 📊 Model Performance
- 🏆 **EfficientNetB0 Test Accuracy: 83.32%**

*Note: Accuracy is based on the project's test dataset and does not represent clinical diagnostic performance.*

## 💻 How to Run the Project

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/vinayakgingine/Brain-Tumor-MRI-Classification.git
```

### 2️⃣ Open Project Folder
```bash
cd Brain-Tumor-MRI-Classification
```

### 3️⃣ Install Requirements
```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Streamlit Application
```bash

```
